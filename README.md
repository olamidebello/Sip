# Olamide SIP

Development repository for a branded SIP softphone and Class 5 platform.

The implementation will be staged and tested. This repository is not yet a deployed phone service. The initial scope is SIP voice calling, secure provisioning, and a Debian 12 deployment layout; mobile push, video, messaging, conferencing, recording, billing, and carrier routing follow as individually verified features.

No Acrobits code or assets are included.
