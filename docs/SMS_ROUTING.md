# Outbound SMS and inbound email controls

Open Administrator > Outbound SMS & email forwarding as super admin. Each active user has smart (existing subscriber-first behavior), Flowroute-only, or blocked outbound routing. Optionally force a currently enabled Flowroute SMS sender assigned to that user; ownership is checked again on every send. Existing feature access, carrier subscription, allowance and carrier acknowledgement checks remain. No new carrier providers or automatic carrier retries are added.

The same screen controls inbound SMS email forwarding to each user's verified current profile email and displays recent email jobs without message bodies. If an inbound DID override selects another recipient, forwarding uses that recipient's preference and verified email. Users can verify or disable forwarding through the existing Subscriber SMS and call routing settings. The delivery worker rechecks active tenant/user, messaging access, preference and verification at delivery time; email address changes require re-verification. Stable provider idempotency keys and existing retry leases are retained.

Requires RESEND_API_KEY and RESEND_FROM in the API environment. This deployment does not create or disclose credentials. The screen reports provider readiness and refuses enabling forwarding when configuration or verification is missing. The installer enables the existing SUBSCRIBER_ROUTING_ENABLED worker flag, preserves all other Compose/environment settings, and backs up source, environment, Compose and images. The outbound_sms_routes table is additive. Policy changes are audited in security_events; stale policy versions are rejected.

Deploy deploy/ansible/sms-routing-local.yml after inbound routing controls are installed. Twelve backend tests cover policy/authentication and verified-email behavior; two GUI tests cover permission and saving. Installer idempotence and configuration preservation were checked locally. Confirm an actual carrier SMS and email after deployment; automated tests use a stub mail sender and do not verify external delivery.
