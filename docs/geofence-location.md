# Calling area centers

Super administrators open Administration → Tenant calling area policy. Enter latitude and longitude, use the device's current location, or click Find address and select a matching result. Set the radius in meters (1–100,000), add the allowed zone, then save. Existing zones have Edit and Remove controls. Up to twenty circles can be saved; a location inside any circle is allowed, subject to the maximum uncertainty setting. Enabling a policy without a zone is rejected.

Address lookup requires `GEOFENCE_GEOCODER_URL` in the private deployment/docker/.env. Set it to an HTTPS search endpoint of a self-hosted or contracted Nominatim-compatible service. The endpoint must accept q, format=jsonv2, limit=5 and return an array containing lat, lon, display_name. Recreate the API container after configuration. No default external provider is contacted, and the donated public nominatim.openstreetmap.org service is not supported. Configure attribution, quotas and privacy requirements for your chosen provider. Address text is sent only after Find address is clicked; results are selected manually. The saved policy stores coordinates and radius, not the address.

Coordinates and browser device location work without geocoding configuration. Device location requires permission and HTTPS. Tenant administrators retain existing coordinate-policy permissions; address search is restricted to super administrators. Policies remain scoped to the signed-in tenant. These are browser checks before outgoing calls; authoritative SIP/SBC restrictions require switch-side enforcement.

## Deploy with server changes preserved

Run `bash deployment/deploy-wallet-geofence.sh` on the SIP server. The Ansible playbook fetches GitHub and applies the two exact feature patches to the current working tree, retaining existing local commits and untracked files. A conflicting patch stops deployment for manual reconciliation; it does not reset, stash, or overwrite the server changes. Re-running skips patches already present. Source and database backups are private under /opt/olamide/backups. The API startup runs the additive wallet-purchase migration. Existing Compose overrides are preserved. The playbook checks the public API health endpoint after rebuilding API and web; purchase and location acceptance still require signed-in testing. Address lookup remains unavailable until GEOFENCE_GEOCODER_URL is configured.

If the script is not yet on a diverged server, download the playbook to a private temporary directory and run it with `ansible-playbook -i 'localhost,' -c local PATH_TO_PLAYBOOK`. Do not run git reset or discard local fixes to obtain the deployer.
