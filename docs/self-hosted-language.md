# Self-hosted messaging language tools

After deployment CI passes, run `bash deployment/deploy-self-hosted-language.sh` from `/opt/olamide/repo` after pulling main. Requires at least 8 GB RAM, Docker disk space and network access for first model downloads. Installer builds a private CPU faster-whisper/Piper service and LibreTranslate (en/es/fr/de), downloads Whisper tiny and the English Piper voice, smoke-tests translation and speech, then enables the API. No OpenAI account/key is required. Services have no public host ports. Existing authentication, messaging permissions, origin validation and request limits apply.

Conversation options → Translation and speech loads available languages, translates a draft, records up to 60 seconds/1 MB for dictation, or reads an English draft aloud. Dictation/translation only change the draft; user must press Send. Long-press a normal text message for Translate message or Read aloud. Translation requires loading/selecting its target first. View-once and removed messages do not expose these actions. Switching contacts or signing out stops local recording/playback and ignores in-flight draft results. Server requests already submitted may finish.

Speech/transcription are processed in server memory/temporary files; temporary recordings are removed after inference. This is not end-to-end encryption. CPU transcription can be slow; unsupported audio fails. English is the only installed synthesis voice. Whisper covers its model's language set, not every dialect. No live call audio interception, two-way call translation, remote-call captions, audio-note transcription or cross-posting is supplied. The earlier full Twitter parity request remains unfinished.

The build and local tests do not prove models run on your server. Verify translation, real-device dictation and audio playback after installation. Models and upstream dependencies have their own licenses (including Piper GPL); retain license notices and the downloaded voice's model card. Disable with LANGUAGE_TOOLS_ENABLED=false in canonical and saved Compose configuration and recreate API; stop the two language services to free memory.
