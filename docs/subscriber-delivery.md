# Subscriber number delivery

See [subscriber-routing.md](subscriber-routing.md) for unified owner controls, verified email delivery, authoritative online SIP registration and carrier ingress forwarding. The `/api/account/subscriber-delivery` endpoint remains a compatibility alias for unified preferences. Registration heartbeats remain accepted for old clients but never establish call routing eligibility. App texts to opted-in same-workspace subscribers can deliver locally without carrier dispatch; other texts retain existing carrier subscription and sender requirements. Existing email jobs use the current verified profile email and current owner opt-in.
